Help

Quick answers about tokens, connections, and uploads.

How do I get a GitHub classic token?

You usually don't need one — Quick Connect (OAuth) or Developer Connect (GitHub App) in the Connect GitHub page cover almost every case. A personal access token is only relevant for advanced setups outside UPGit's normal flow.

How do I get a Vercel token?

Open vercel.com/account/tokens, create a new token, then paste it into UPGit's Vercel tab. It connects independently from your GitHub account.

Is my token safe?

Yes. Tokens that need to live on the server are encrypted, and UPGit never exposes them back to the browser. You can remove your Vercel token or disconnect GitHub anytime from Settings → Security.

What can I upload?

Individual files, a whole folder, or a .zip. UPGit reads the structure automatically and shows you a preview before anything is committed.
